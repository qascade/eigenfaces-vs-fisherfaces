--- S5: why S_W cannot be inverted in pixel space ---
  Yale: d = 32256, N = 1520, c = 38

  theory: rank(S_W) <= N - c = 1482
  measured rank(S_W)         = 1482
  so S_W is singular: rank 1482 << d 32256
